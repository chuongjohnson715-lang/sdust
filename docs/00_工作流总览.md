# 00 ｜ 工作流总览

> 这套东西只解决一个问题：把**学校课程的录播**变成**可回溯到原始证据的考前复习材料**。

## 1. 数据流

```
录播页（播放器 iframe）
  ├─ 音频：按 chunk 精准取字节（仅音轨）      ≈ 34 MB / 节
  └─ 视频：只取关键帧（I 帧）抽图             ≈ 62 MB / 节
        ↓
证据层（pipeline.py，12 阶段，状态机 + 断点恢复）
  probe → audio → asr → slides → ocr → notes → verify
        + tracks_audio → tracks_asr → tracks_slides → tracks_ocr → tracks_align
        ↓
学习层（semantic_review.py / semantic_auto.py）
  evidence_pack → merge → render → validate
        ↓
交付层（build_deliverables.py）
  五件套 + 证据夹 + 脑图 HTML + 考试重点 HTML
```

## 2. 两条取数路线

| 路线 | 输入 | 代价 | 产物差异 |
|---|---|---|---|
| **A 双轨** | 已有整包 mp4（双路：摄像机 + 屏录） | 磁盘大 | 时间分辨率 2 s，课件页最全 |
| **B 轻量（推荐）** | 只从平台取音频 chunk + 关键帧 | ≈ 96 MB / 节 | 时间分辨率受采样步长限制（默认 15 s） |

轻量路线会先用「音频 + 抽帧」合成一条屏录 mp4，再喂给同一条主管线，
所以**证据层逻辑零改动**，产物结构与双轨版一致。

## 3. 产物树（一门课）

```
courses/<课程名>/
├── 期末考试重点与考情分析.docx     课程级：题型 + 按讲次考点图
├── 全课程知识体系与思维导图.docx   课程级：章↔讲次 + 必考点明细 + 依赖图
├── 全课程思维导图.html             全课程一份，节点标讲次，可折叠搜索
├── 考试重点.html                   全课程一份，按判定/讲次筛选（骨架见 templates/考试重点.html）
├── 每节课的简短总结/
│   ├── 00_使用说明.docx            课程级唯一一份
│   └── MM-DD_第X讲-<章或主题>/
│       ├── 02_逐节课知识点与课堂内容记录.md
│       └── 04_证据文件夹/          逐字节原样，不得改动
└── （可选）原样/<课程名>/…          精修前的规则法产物，留档
```

命名规则：**日期在最前**（`09-07_第三讲-第2章`）——只说「第几讲」不带日期，无法判断是哪一次课；
第三段只写**可确证的章号**，查不到就写主题，不猜。

## 4. 三份课程级文档的格式

| 文档 | 格式 | 说明 |
|---|---|---|
| 期末考试重点与考情分析 | **`.docx`** | 交付目录不留 `.md` 副本 |
| 全课程知识体系与思维导图 | **`.docx`** | 同上 |
| 每节课的简短总结/00_使用说明 | **`.docx`** | 同上 |
| 各讲 `02` / `04` | `.md` | 证据，随讲存放 |

转换：`python scripts/md_to_docx.py <x.md>`（Windows + Word COM，不装依赖）。
改完内容务必重跑转换，再删掉 md。

## 5. 每一步的验收

| 步骤 | 验收命令 | 通过标准 |
|---|---|---|
| 取数 | `python scripts/run_lesson_browser.py --activity …` | 生成 `audio/raw_16k.wav` + `slides/slides.json` |
| 管线 | `python scripts/pipeline.py --window 0:60 --work-root ./_work/data` | 12 阶段全 `succeeded` |
| 语义 | `python scripts/semantic_review.py --data … --out …` | `validate` 无悬空引用 |
| 交付 | `python scripts/build_deliverables.py …` | 自检通过，退出码 0 |
| 精修后 | `python scripts/check_refined.py <课程名>` | 输出「问题 0」 |
| 直链守卫 | `python scripts/test_light_common.py` | 全部 PASS / 允许的 SKIP |
