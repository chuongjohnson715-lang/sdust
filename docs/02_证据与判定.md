# 02 ｜ 证据与判定：每条结论都要能倒查

> 这套工作流的底线：**可以少写，不可以编**。写下的每一条结论，都能在 `04_证据文件夹/`
> 里找到原文，并在播放器里找到位置。

## 1. 四级证据（A / B / C / D）

| 分册 | 来源 | 典型内容 | 可信度 |
|---|---|---|---|
| **A** | 课件 OCR | 标题、定义、例题、代码、表格 | 高（原文），但有 OCR 噪声 |
| **B** | 课堂转写 | 老师逐段讲的话（30 秒块级） | 中，无句级时间戳 |
| **C** | 课程要求 | 大纲、考核说明、作业要求、教材信息 | 高，但常常是空槽 |
| **D** | 课堂原话待回听 | 转写里疑似考试信号、数字、范围句 | 待核，必须回听确认 |

分册文件命名固定为 `证据源A_…` / `证据源B_…` / `证据源C_…` / `证据源D_…`，
**禁止用数字前缀**（会与顶层 `01_/02_/03_` 撞号）。

`04_证据文件夹/` 一旦生成，**逐字节原样保存**；精修只改 `00–03`，不动 `04`。

## 2. 引用格式

```text
〔A-007 · P.012 · 08:30〕
 └ 分册 └ 编号 └ 源页码 └ 时间（B/D 才有，±30 s）
```

- 编号在证据索引里唯一，正文引用必须能在索引「视图三」查到，否则算**悬空引用**；
- 页码不得超过该分册最大页（`P.xxx` 越界会被机检抓出）；
- B/D 分册的时间是 **30 秒块的起点**，只能写到分钟，**禁止伪造句级时间戳**
  （本地 ASR 模型是非自回归的，本身不输出时间戳）。

## 3. 判定档位（只认老师原话）

| 判定 | 含义 | 依据要求 |
|---|---|---|
| ⭐ 必考 | 老师对**本课程**明确说要考 | 必须带 A 级原话 + 时间 |
| ⭐ 必记 | 老师说「一定要记住 / 必须掌握」，但未明说考 | 带原话 + 时间；不得升级成必考 |
| 重点 | 老师用强词，但语境是考研 / 统考 | 标「考研向」，不得写成必考 |
| 了解 | 老师说「了解一下就行」 | 带原话时间 |
| 教材补 | 录播没讲，按教材补齐 | 写明「无课堂证据」 |
| ⛔ 不考 | 老师明确说本课程不考 | 带原话时间 |
| 待确认 | 有信号但转写残缺 / 对象不明 | 写「待回听」 |
| 非考点 | 教务事务、作业要求、复习方法 | 不参与优先级排序 |

三条禁令：

1. **「正常讲授」≠「考试重点」**——老师只是在讲，不能判必考；
2. **「考研 / 408 常考」≠「本课程必考」**——最多标「重点（考研向）」；
3. **没有原话就写「教材补」或「待确认」**，不许用常识补一个「必考」。

## 4. 精修四条标准

机器生成的五件套只保证「结构对、引用能对上」；`00–03` 必须人工/Agent 精修：

| # | 标准 | 要求 |
|---|---|---|
| 1 | 01 考情只留真考点 | 删空泛标签（任务性提示、一般性指向）；准确归类（「缺勤取消资格」是考勤，不是考试内容）；空段标红并写明原因，不硬凑 |
| 2 | 02 逐讲只留知识点 | 砍掉时间轴、段落边界、整段原话（下沉到 04）；按老师原词分级：掌握/记住 → ⭐，了解 → 不标，描述/熟悉 → ○ |
| 3 | 03 体系只收已确定 | 学分/学时/教材/教师/先修收进 03；补演变链与真正存在的依赖，不按时间顺序硬串 |
| 4 | 诚实分级 | 见上一节；查不到的保留原引用并标「待核」，宁可空着也不猜 |

精修实测压缩率 70–85%（规则法版单节 00–03 约 70–100 KB，精修后约 15–20 KB）。

## 5. 生成器已知缺陷（必须人工清掉）

用规则法批量生成时会稳定出现下列问题，精修时逐条检查：

| # | 缺陷 | 表现 |
|---|---|---|
| 1 | 占位语批量复制 | 「一般性强调，未直接指向考试」在同一节出现几十遍 |
| 2 | 判定与标签自相矛盾 | 标题写「未直接指向考试」，却进「明确必考」并打五星 |
| 3 | 课堂事务当考点 | 「交作业」「点名」被判成 P0 |
| 4 | 真考试信号被抹平 | 老师明确说「考试要考手写操作」，却被标成「未直接指向」 |
| 5 | 证据编号重号 | 同一节多处用同一个 `A-001·P.001·00:00` |
| 6 | OCR 乱码当模块名 | 版本号、IP、控制台输出被当成知识点 |
| 7 | OCR 原文未清洗 | 页眉里「兼容模式 / 立即登录」混进正文（证据册保留原样，正文要清洗） |
| 8 | 串课程 / 模板残留 | 01/03 里出现别的课程名 |
| 9 | 模块↔知识点绑定丢失 | 大量「本段未绑定知识点」 |
| 10 | 依赖关系臆造 | 按时间顺序用箭头硬串所有模块 |
| 11 | 段落边界失真 | 十几秒的片段被生成独立知识点卡 |
| 12 | 条数与占比不自洽 | 条数越少、占比反而越高 |

## 6. 内容判定的硬规则

1. **判「空课」前至少听 10–15 分钟**：前 60 秒没声音是常态（点名、等人）。
   空课必须同时满足：音频 ≥10 分钟、前 15 分钟 RMS 低、15 分钟内转写≈0 字；
   否则只能写「待核实」。
2. **禁止拿二次压缩的 mp4 当语料**：压缩会让 ASR 冒出凭空词。ASR 只吃原始音轨解码出的
   16 kHz wav；合成 mp4 时音频必须 PCM 直通。
3. **考情权重按讲次定位**：第 1 讲、倒数第 2 讲、最后 1 讲必然讲考试口径，权重最高。
4. **取消「一页速记卡」**：考前速记由课程根 `考试重点.html` 承担，03 不再写速记表。
5. **三份课程级文档只出 `.docx`**：考情分析、知识体系、每节课的简短总结/00 使用说明；
   交付目录不留 `.md` 副本。各讲 `02` 与 `04` 仍是 `.md` 证据。

## 7. 机检：精修后必跑

```bash
python scripts/check_refined.py <课程名> [讲次目录]
```

检查项：

- 正文引用编号是否都能在 `04` 找到（悬空引用）；
- `P.xxx` 是否超过该分册最大页（越界页码）；
- 是否残留 `{{占位}}`、`<!--注释-->`、`TODO`；
- `04_证据文件夹/` 是否与 `原样/` 下的副本逐字节一致；
- 是否残留已取消的「一页速记卡」；
- 课程级文档是否还留在逐讲目录里。

通过标准：输出 **「问题 0」**，退出码 0。

## 8. 诚实边界

- ASR 是非自回归模型，**不输出置信度**，字段如实置 `null`，不伪造分数；
- 画面出现时间 ≠ 讲解时间，只做时间窗关联，不写成「讲到第 X 页时正好第 Y 秒」；
- 查不到的内容保留「空缺」并写明原因，不拿常识补写；
- 冲突不取舍：两侧原文与页码并列，标「待核实」。
