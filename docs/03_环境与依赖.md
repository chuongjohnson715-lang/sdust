# 03 ｜ 环境与依赖

> 这套东西只在本地跑：**取数阶段联网，模型推理阶段全离线**。不上传任何音视频。

## 1. 目录与解释器

推荐结构：

```
<仓库根>/
├── AGENTS.md              工作流总纲（Agent 主入口）
├── README.md              人类入口
├── run_course.py          端到端编排入口
├── coursereview/          登录 / 发现 / 下载 / 编排 / 规则语义
├── scripts/               取数、管线、语义、交付、机检
├── templates/             五件套空白骨架 + 脑图模板
├── docs/                  本目录
├── .secrets/              凭据（gitignore，绝不入库）
├── .state/                登录会话、下载进度、清单（gitignore）
├── _work/                 下载与中间产物（gitignore）
├── input/                 若已有本地双轨 mp4，放这里（gitignore）
└── courses/               最终交付物（可入库或单独管理）
```

解释器建议单独建 venv，并把它的绝对路径设为 `COURSE_REVIEW_PYTHON`；
所有子进程（管线、语义、交付）都用这一个解释器。

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
```

> `requirements.txt` 里的版本是**本机验证过的组合**，不是强制约束。
> 原则是「只调用、不安装」：能跑就别升级，升级前先跑一遍 `test_light_common.py`。

## 2. 外部二进制

| 程序 | 用途 | 说明 |
|---|---|---|
| `ffmpeg` | 解码、切块、合成 mp4、转 wav、抽帧 | 需带 H.264 与 AAC 解码器 |
| `ffprobe` | 读时长、轨道、帧率 | 缺省取 ffmpeg 同目录 |

解析顺序（[`scripts/paths.py`](../scripts/paths.py)）：环境变量 → `PATH` → 常见安装位置。
找不到时**导入即报错**，并在错误信息里给出设置示例。

## 3. 本地模型（离线）

| 模型 | 用途 | 默认位置 | 覆盖变量 |
|---|---|---|---|
| SenseVoiceSmall | 中文语音识别 | `~/.cache/modelscope/iic/SenseVoiceSmall` | `COURSE_REVIEW_SENSEVOICE` |
| EasyOCR 中文模型 | 课件 OCR | `~/.EasyOCR/`（首次运行自动下载） | — |

首次准备模型需要联网，之后设置 `MODELSCOPE_OFFLINE=1` 可确保不再联网。

> 换机器时把模型目录拷过去即可，不必重新下载；模型体积较大，不要放进仓库。

## 4. 环境变量一览

| 变量 | 作用 | 缺省 |
|---|---|---|
| `COURSE_REVIEW_PYTHON` | 子进程使用的解释器 | 当前解释器 |
| `COURSE_REVIEW_FFMPEG` | ffmpeg 绝对路径 | `PATH` / 常见位置 |
| `COURSE_REVIEW_FFPROBE` | ffprobe 绝对路径 | ffmpeg 同目录 |
| `COURSE_REVIEW_SENSEVOICE` | SenseVoiceSmall 目录 | `~/.cache/modelscope/...` |
| `COURSE_REVIEW_INPUT` | 本地 mp4 默认输入目录 | `<仓库>/input` |
| `COURSE_REVIEW_WORK_ROOT` | 下载与中间产物根目录 | `<仓库>/_work` |
| `COURSE_REVIEW_OUT` | 五件套交付根目录 | `<仓库>/courses` |
| `COURSE_REVIEW_PROFILE` | 浏览器持久化配置目录 | `.secrets/browser-profile` |
| `COURSE_REVIEW_BYPASS_PROXY` | 设为 `1` 时 Chromium 直连（本地代理挂了时用） | 不设置 |
| `LMS_BASE` / `LMS_PORTAL` / `LMS_CAS` | 平台入口（也可写在 config 里） | `example.edu` 占位 |
| `COURSE_REVIEW_PLAYER_BASE` | 播放器域（直链 Referer/Origin） | `http://lms.example.edu:8002` |
| `MODELSCOPE_OFFLINE` | 设为 `1` 强制离线推理 | 不设置 |

## 5. 凭据

```bash
mkdir -p .secrets && cp config.example.json .secrets/config.json
# 填账号、密码、课程关键字、平台入口
```

- `.secrets/` 在 `.gitignore` 中，**永远不要把 config.json 提交到仓库**；
- 日志与异常统一走 `redact()`，密码与账号不会出现在输出里；
- 账号只有**只读**用途：看课程、播放录播。不提交、不发帖、不改任何资料。

## 6. 平台入口怎么填

`config.json` 里三处入口对应：

| 字段 | 含义 | 示例 |
|---|---|---|
| `lms_base` | 课程/播放器所在的教学平台 | `https://lms.example.edu:8085` |
| `portal_url` | 统一门户里的应用中心（CAS 回跳目标） | `https://portal.example.edu/application-center` |
| `cas_login` | 统一身份认证登录页 | `https://cas.example.edu/cas/login` |

`target_course_keyword` 用来在「我的课程」里匹配目标课程，填课程名里的关键字即可。

如果平台改版，只需要改**取数层**（`coursereview/discover.py`、`fetch.py`、
`scripts/captures_api.py`、`scripts/fetch_tracks_v2.py`），证据层不用动。

## 7. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 下载全部 403 | 签名直链过期 / 用了旧 URL | 重新取配置；确认走了 `context.request`；跑 `test_light_common.py` |
| 取配置时流量暴涨 | 播放器自动拉了预览流 | 确认已按域名阻断存储域（媒体域），不是在拉完再拦 |
| 进程被 OOM 杀掉 | 并发跑 ASR / 把帧累积进内存 | ASR 串行；抽帧只保留前一帧灰度图 |
| `ERR_PROXY_CONNECTION_FAILED` | 本地代理客户端没开 | 设 `COURSE_REVIEW_BYPASS_PROXY=1` 直连 |
| 登录页停在验证码 | 会话过期或平台启用了风控 | 首次人工过一次验证码，之后复用会话；不识别、不绕过 |
| `find src` 类报错 | 路径含空格未加引号 | Windows 下统一用引号包住路径 |
| Word COM 转 docx 失败 | 未安装 Word / 后台残留进程 | 确认已装 Word；必要时结束 `WINWORD.EXE` 后重试 |
| 合成 mp4 后 ASR 胡言乱语 | 音频被二次压缩 | 合成时必须 PCM 直通，用原始 16 kHz wav |

## 8. 磁盘与清理

- 单节中间产物可到数百 MB；批量跑前先确认工作盘余量；
- 删除走回收站（不会立刻释放空间），需要时手动清空；
- 仓库只应保留 `courses/` 与源码；`_work/`、`input/`、`.state/`、`.secrets/` 一律不入库。

## 9. 耗时参考（本机实测，仅作排期）

| 步骤 | 单节耗时 |
|---|---|
| 取音频 chunk | 1–2 分钟 |
| 取关键帧 + 解码 | 2–5 分钟 |
| ASR（CPU） | 与音频时长接近 1:1 |
| OCR（每页） | 约 0.05 分钟/页 |
| 语义 + 交付 | 1–3 分钟 |

课件页数差异极大（同课程 60–250 页），排期按「页数 × 0.05 分钟」粗估，
ASR 与 OCR 阶段串行执行。
