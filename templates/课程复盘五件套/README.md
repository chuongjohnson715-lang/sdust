# 课程复盘五件套 · 空白骨架

> 这是**格式模板**，不是内容。`{{...}}` 是待填占位符，`<!-- ... -->` 是给填写者的说明（定稿前删除）。
> 格式契约的权威定义在仓库根的 `AGENTS.md` 第 6 节；本目录只是它的可执行形态。

## 一、怎么用

```powershell
# 在仓库根执行：复制骨架 → 替换 {{课程名}} 与 {{课程简称}} → 报告剩余占位符
powershell -NoProfile -ExecutionPolicy Bypass -File .\templates\new-course.ps1 `
  -Target ".\<课程简称>-<学期>" -CourseName "<课程全名>"
```

脚本只做机械动作（复制 + 替换课程名/简称 + 统计占位符），**不做任何内容推断**。
`new-course.ps1` 必须保持 **UTF-8 with BOM**：Windows PowerShell 5.1 读无 BOM 的中文脚本会乱码并报语法错误。

## 二、占位符约定

| 写法 | 含义 | 谁来填 |
|---|---|---|
| `{{课程名}}` | 课程全名 | 脚本自动替换 |
| `{{...}}` 其他 | 未知内容，必须由证据层推导后填写 | 语义层（人/Agent） |
| `<!-- ... -->` | 填写说明，定稿前必须全部删除 | 语义层 |

## 三、填充顺序（不可颠倒）

```
04 证据分册 → 04 索引（视图三 → 视图二 → 视图一）
   → 02 逐讲 → 03 知识体系 → 01 考情 → 00 使用说明 → assets 脑图 → 自检
```

**为什么 01 放后面**：01 是判决书，判决必须引用已存在的证据。先写 01 一定出现「结论等证据」，随后被迫回填，导致引用与原文对不上。

## 四、定稿验收（两条都必须为 0）

```powershell
# 1) 残留占位符
Get-ChildItem -Recurse -Include *.md,*.csv,*.html | Select-String -Pattern '\{\{|<!--' | Measure-Object

# 2) 悬空证据引用：正文出现的每个编号，都要能在 04_证据文件夹/00_证据索引.md 视图三查到
```

再逐项打勾 `AGENTS.md` §7 的 9 条自检清单。

> 课程级三份文档（01 / 03 / 00）定稿后须转成 `.docx` 并删除同名 `.md`，见 `AGENTS.md` §6.6。

## 五、文件清单

```
<课程>/
├── 00_使用说明.md
├── 01_期末考试重点与考情分析.md
├── 02_逐节课知识点与课堂内容记录.md
├── 03_全课程知识体系与思维导图.md
├── 04_证据文件夹/
│   ├── 00_证据索引.md
│   ├── 证据源A_课件.md            ← 改名：证据源A_<真实来源>，如 证据源A_课件第2章
│   ├── 证据源B_课件.md
│   ├── 证据源C_实验报告与配置.md   ← 无此类材料时保留文件、写「本课程无此类材料」并说明原因
│   ├── 证据源D_课堂原话待补录.md   ← 空槽，必须保留
│   └── 证据页码对照表.csv
└── assets/
    └── 全课程思维导图.html
```

## 六、三条硬约束（写在这里，防止填着填着忘了）

1. 证据分册**禁止**用数字前缀（会与顶层 `01_/02_/03_` 撞号），必须用 `证据源A/B/C/D`。
2. 没有 A 级（课堂原话）证据时，01 第四节「明确不考」**留空并说明**，不得写任何「不考」结论。
3. 冲突项**不取舍**：两侧原文 + 两处页码并列，标「待核实」。
