## 三、补录操作路径（照做即可）

```
1. 取课堂录音（任一路 mp4 的音轨均可，优先高电平轨）
2. 用本仓 python 环境跑 SenseVoice，得到 30s 块级转写（asr/*.jsonl）
3. 用上表「检索线索」逐个关键词检索，定位候选块
4. 回听该 30s 窗口 ±1 块，人工确认原话（8kHz 转写不可直接当原话用）
5. 按下述格式填入对应空槽，状态改「已核验」，并写真实时间戳
6. 回填 00_证据索引.md 视图一（该空槽对应的结论编号）
7. 若结论因此升级（推定 → 必考/不考），同步改 01 与 00 的阅读须知
```

**填入格式**（与 A/B/C 分册一致）：

```
### EV-00X ｜ 证据页 P.0XX
- **源文件**：{{音轨文件}} @ {{mm:ss}}–{{mm:ss}}（块级时间戳，非句级）
- **原文**：
  > {{人工回听后确认的文字}}
- **支撑结论**：{{把哪条推定升级为 A 级}}
- **可信度**：高（本人回听确认）／中（转写直读，未回听）
```

> ⚠️ **禁止**：把 SenseVoice 的块级转写直接当「原话」填入并标「高」。8kHz 远场下同一句可能转成三种结果（「7望/希望/期望」），未回听只能标「中」并注明「转写直读」。
